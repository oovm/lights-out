Lights Out Solver
=================

Rust library for solving Lights Out puzzles via Gaussian elimination.

## Layout

```text
projects/
  crates/
    lights-out-solver/   # Rust library
  packages/
    homepage/            # demo site (VMZ host shell)
```

## Build

```bash
cargo test --release
# or: pnpm test
```

## Web

```bash
pnpm dev:web
```
